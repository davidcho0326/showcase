실제 자동화 사례 영상

에이전트가 코드/JSON으로 만든 결과. 두 가지 패턴.

① 데이터 리포트 → 영상 (영상 소스 ZERO)

ST 26SS 대표님 보고자료 PDF → JSON 8씬 → React 컴포지션 렌더. mp4/mov 자산 0개, 100% 코드/CSS로 생성. 34초 / 1920×1080.

② 브랜드컷 자동 생성

모델 영상 위에 배경 교체·그래픽 오버레이를 코드로 합성. NLE 수작업이 함수 호출로 대체되는 패턴 — Premiere MCP도 같은 방식.

언제 무엇을 쓸 것인가

  • 브랜드 프로모 · 보고용 영상 — Remotion (재사용·데이터 자동화) + Hyperframes (footage 위 오버레이)
  • 기존 촬영본 컷편집 · 컬러 보정 · 정밀 편집 — Premiere Pro MCP · 코딩 에이전트가 NLE를 손처럼 조작 (269 tools)
  • 모바일/숏폼 CapCut 워크플로우 자동화 — CapCutAPI(OSS) 또는 SaaS 우회 (공식 API 부재 우회)
  • 마케팅 광고 변형 N개 자동 생성 — Creatomate · JSON2Video · Shotstack — JSON 한 장으로 즉시 변형

핵심 인사이트: NLE의 자리에 코드 에이전트가 들어간 셈. 마우스 클릭이 함수 호출로 바뀌면 영상 작업도 "코드 리뷰"가 가능해진다.
